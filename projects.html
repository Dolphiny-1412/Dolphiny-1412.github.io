P.02Cryptographic Protocol Analyzer ★ FEATUREDFinds insecure protocols and plaintext credentials in packet captures.SECURITY+
WHAT IT DOES

Reads a PCAP/PCAPNG file and checks it against predefined rules — no machine learning. Each finding gets a severity (Critical to Low) and a suggested fix.

KEY POINTS
▸ INPUT — .pcap / .pcapng files, parsed with Scapy (IPv4 TCP/UDP)
▸ CHECKS — insecure-protocol ports, credential keywords, SSLv3 / TLS 1.0 / 1.1
▸ OUTPUT — Streamlit + Plotly dashboard, CLI, CSV export
▸ LIMITS — offline and heuristic; no TLS decryption or cipher-suite checks
CONTEXT

University computer security project
