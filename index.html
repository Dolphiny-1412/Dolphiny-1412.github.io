F.02 — FEATURED · NETWORK SECURITY

Cryptographic Protocol Analyzer

Rule-based analyzer for PCAP/PCAPNG captures. Flags insecure protocols, deprecated SSLv3/TLS 1.0/1.1 handshakes and plaintext credential keywords, each rated Critical to Low with a fix.

▸ INPUT — .pcap / .pcapng files parsed with Scapy (IPv4 TCP/UDP)
▸ RULES — port-based table (HTTP, FTP, Telnet, POP3, IMAP, SMTP, TFTP, SNMP, Syslog), payload keyword scan, TLS record-header check
▸ OUTPUT — severity-rated findings in a Streamlit + Plotly dashboard, a CLI, and CSV export
▸ SCOPE — university project; offline and heuristic — it does not decrypt TLS or inspect cipher suites
