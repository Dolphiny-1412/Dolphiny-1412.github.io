# Youssof "Dolph" Ahmed Aly — Portfolio

A single-file portfolio site: `index.html` (all CSS and JavaScript inline, no build step).
Fonts load from Google Fonts. Six colour themes are built in (default: Dusk) and the visitor's choice is remembered in the browser.

## Deploy with GitHub Pages
1. Create a new repository (a repo named `<username>.github.io` serves from the root URL).
2. Upload `index.html`, `.nojekyll` and this `README.md` to the `main` branch.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save.
4. After a minute the site is live at `https://<username>.github.io/` (or `/<repo-name>/` for other repo names).

## Editing
Open `index.html` in any editor. Project cards, the about text and the experience log are plain HTML. The default theme is set near the bottom of the file (search for `dusk`).
